不是录屏，是代码画的。整片由 render(t) 一个纯函数驱动—— 给同一个 t 永远出同一帧，没有随机数、没有 Date.now()、没有 CSS 动画。 所以你可以在这里随便拖时间轴定格，也可以把它当无头录制的源。

00:00.0 / 00:42.0

分镜

它是怎么做的

页面加载后先注册字体与徽标位图，再暴露一个全局对象： window.SopeekReel = { duration, render(t), play(), pause(), seek(t) }。 播放器只做两件事——推进时钟、调用 render(t)；画面里没有任何自身状态。

  • 确定性：同一 t 重复渲染，像素完全相同（可用 render(18.4) 验证）。
  • 无外部依赖：徽标来自 assets/Sopeek.png，字体走 Windows 自带 Bahnschrift / Segoe UI，不请求 CDN。
  • 可录：任一时刻都能定格、逐帧步进，方便无头截图或 OBS 采样。
  • 可剪：分镜时间点是常量数组，改时长只改一个数字。
// 控制台里直接玩 SopeekReel.pause() SopeekReel.render(18.4) // 定格到第 18.4 秒 SopeekReel.duration // 42

需要真正的 MP4 时，用 render(t) 按 30fps 逐帧出图再编码即可； 这一页刻意不内嵌视频文件，保持仓库轻量、也避免自动播放与编码器差异。
