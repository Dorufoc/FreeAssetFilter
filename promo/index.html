01FLOW

一个工作流，
替你关掉 四个窗口

资源管理器里翻目录、看图软件里放大、播放器里拖进度、PDF 阅读器里找页码——这些动作在 Sopeek 里被压成一条直线。左侧选择器负责「找」，中间储存池负责「挑」，右侧预览器负责「看」，三者共享同一套选中状态与同一套快捷键。

SELECT · STAGE · INSPECT
01

找

选择器把目录摊平成卡片墙：缩略图直接告诉你这是什么，而不是让你先记文件名。

  • 卡片 / 列表双视图，列数自适应，Ctrl+滚轮缩放
  • 文件名正则筛选，不区分大小写
  • 名称 / 修改时间 / 大小 / 创建时间 × 升序降序 = 8 种排序
  • 路径收藏夹 + 历史 + 全部磁盘一览
  • 隐藏文件 / 受保护系统文件两级开关
  • 后台批量生成缩略图，按需清理缓存
02

挑

左键拖出一块橡皮筋框选，右键把整批文件塞进储存池——它是工作区里唯一「会留下」的地方。

  • 左键拖拽框选，右键已选批量入池
  • 储存池网格 / 列表两种视图，可重命名、删除、清空
  • 导出文件、导入导出路径、自动备份
  • 文件可直接拖进池，也可拖进桌面浮窗
  • 整个池可折叠，给预览器让出宽度
03

看

选中即预览，舞台按文件类型自动换装：图像、视频、音频、PDF、Office、代码、压缩包、字体、文件夹。

  • 8 类预览器，近 100 种扩展名
  • 详细信息按类型展开（EXIF / 时长 / 音频标签）
  • MD5 / SHA1 / SHA256 后台流式哈希，带进度
  • 统一操作栏：复制、系统打开、定位目录、清除预览
  • 预览器画布默认 16:9，可按窗口自适应
02PREVIEW

一个画布，按类型换装

预览器不是「打开方式」，而是画布的一部分：切换文件时只换装内部实现，顶栏、操作栏、全屏行为保持一致。七类预览器共享同一套外壳，只是内部实现按格式族换装。

03FORMATS

近 100 种扩展名，不用另装软件

预览器按「格式族」注册：同一族共享解码管线与降级策略。原生库缺失时自动回退纯 Python 实现，功能不减、只是慢一点，应用不会因此崩溃。

04LAYOUT

两种布局，同一种秩序

经典三栏把「选择 / 暂存 / 预览」平均分给三块；New 布局让选择器独占左栏，预览拿到更宽的画布，储存池与信息面板退到下方并排。切换只改排列，不改组件。

SPLIT · STACK · FLOAT

操作习惯

  • 左键单击选中并预览；鼠标侧键后退
  • 卡片或空白处拖拽框选，右键已选批量入池
  • 单击信息条目复制，右键复制全部字段
  • 分隔条可拖、双击重置；经典布局储存池可折叠
  • Ctrl+方向键或 F6 在三个区域间切焦点

三个区域

  • 选择器：路径栏、6 个 28px 导航按钮、72×102 卡片网格、底部状态
  • 储存池：攒素材的地方，跨目录保留顺序
  • 预览器：顶栏四个统一操作 + 类型化舞台
  • 信息面板：常驻字段 + 按类型展开 + 流式哈希
  • 预览画布默认 16:9、最小 640×360

桌面浮窗

  • 常驻桌面的圆形入口，把文件拖进去即入池
  • 展开后是一块精简储存池，贴边自动吸附
  • 记住上次位置，开机随应用一起回来
  • 与主窗口共享同一份池与同一份顺序
  • 适合「一边看网页一边攒素材」的场景

06ENGINE

重活交给 Rust，界面只负责画

目录扫描、排序、高亮、Markdown、字体解析、哈希、编码探测、EXIF、批量复制、SVG 换色、7z 列表、PDF 取词——这些高频路径被移进 spk_core（cdylib）。界面线程只拿结果。

07START

装上，就不想再开资源管理器

两种进入方式：拿现成安装包，或者从源码跑起来。后者需要 Python 与 PySide6。

INSTALL
powershell — sopeek
# 1 · 安装包（推荐）
› Sopeek-2.0.0-windows-x64.exe
› 双击安装，首次启动会预热原生库

# 2 · 从源码运行
› git clone https://github.com/Dorufoc/Sopeek.git
› cd Sopeek
› python -m venv .venv
› .venv\Scripts\activate
› pip install -r requirements.txt
› python -m sopeek.app.main

# 3 · 指定目录启动
› python -m sopeek.app.main --open-path "D:\Assets"

环境要求

Windows 10 / 11 64 位；源码运行需要 Python 3.9+ 与 PySide6 6.10+（无边框方案的下限）。视频播放额外需要 OpenGL 3.0+。

你的数据

配置、缓存、缩略图与哈希结果都在 %LOCALAPPDATA%\Sopeek\data，可用 SPK_DATA_DIR 改位置。其中 config 与 assets 不可再生，备份请整目录复制。
